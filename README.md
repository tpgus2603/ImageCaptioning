# ImageCaptioning

분산 머신러닝으로 멀티 모달 데이터(이미지 ,텍스트) 처리 및 이미지 캡셔닝 모델 구현 , 멀티 GPU를 활용하기 위해

torch.distributed를 이용하여분산 시스템을 구축한 코드가 pair로 존재합니다.

주피터 노트북 환경에서 동작하는 코드이므로 터미널을 통해 파이썬 코드를 실행시 적절한 수정이 필요합니다.

멀티 gpu에 관련된 코드를 실행하기 위해선 터미널 환경에서 
python -m torch.distributed.launch --nproc_per_node=4 test.py  명령어를 통해 실행하세요


연구배경
-
딥 러닝은 긴 학습 시간이 요구되는 학습 방식으로, 그중에서도두 가

지 이상의 모달리티의 데이터를 처리하는 멀티모달 데이터에 대한 딥 

러닝의 경우 학습 시간이 더욱 길어진다. 이런 멀티 모달 데이터를 좋

은 성능으로 처리하기 위해 최근에는LLM기반의 트랜스포머 모델을 

활용한다.LLM모델을 처리하기 위해서는 고성능의GPU가 필요하다.

그러나 LLM이 각광받음에 따라GPU 부족으로 인해 대용량 메모리

와 우수한 성능을 가진H100이나A100과 같은 고성능GPU 를 확

보하는 것이 매우 어려워졌다. 이러한 문제를 해결하기 위해, 다중

GPU 를 효과적으로 사용하는 병럴 컴퓨팅을 활용하면 멀티모달 데

이터에 대한 딥러닝 같이 오랜 시간이 학습 시간을 최적화할 수 있다

는 아이디어를 바탕으로 연구를 시작했다. 이 연구를통해효과적인 딥

러닝 모델과 병렬 컴퓨팅 기법을 찾아내는것이 연구의  최종 목표이다


연구 진행 과정
-

연구에서는 텍스트와 이미지 두가지 모달리티를 처리하는 이미지 

캡셔닝을 수행하면서 병렬 컴퓨팅에 효과적인 딥러닝 모델을 구현

하여 효과적인 병렬 처리 방식을 고안한다. 이를 수행하기 위해 트

랜스포머 기반 다수의 딥러닝 모델을 구현 하고각 모델에 대해 싱

글GPU환경에서 학습, 멀티GPU환경에서 학습을 수행하며 결과

를 대조하고 분석하는 실험을 행하며 연구를 진행했다. 연구를 진행

하면서 실험에 적용된 핵심 개념은 다음과 같다.

 **1.데이터 병렬 처리**
 
분산 병렬처리 기법 중 하나로 데이터를 다수의 노드,gpu로 나누어 

병렬 계산을 수행하는 방식이다. 이를 구현하기 위해 파이토치에서

는 DistributedDataParallel(DDP)이라는 모듈을 제공하는데 

핵심은 멀티프로세싱 기법이 적용된다는 것이다. GPU당 하나의 

프로세스를 생성하고, 각 프로세스가 해당GPU의 모델 복사본과 

데이 터를 관리한다. 이 접근 방식은 단일 프로세스 방식에서 생기

는 병목을 제거한다. 각 프로 스는 모델의 복제본을 독립적으로 보
유한다. 

DDP 의 동기화 방식은 일관된 학습을 보장하기 위해 각step(미
니 배치에 대한forwar및backward학습 단위)마다 이루어진
다. 

**2.torch.distributed**

torch.distributed는 분산 환경의 다중 노드 간의 통신 혹은 싱글 
 
노드에서 멀티GPU를 효율적으로 처리하는 Pytorch에서 제공하

는 라이브러리이다. 여러 프로세스가 서로 통신할 수 있는 환경을 

제공하는 것이 핵심이다. 이를 통해 각 프로세스가 다른 프로세스와 

데이터를 주고받으며 작업을 동기화할 수 있다. 예를 들어, DDP를 

사용하면 각 프로세스가 그래디언트를 계산한 후, 

torch.distributed를 통해 프로세스 간 그래디언트를 공유하고 

평균을 계산하여 동기화한다. 따라서DDP를 쓰면 이 라이브러리

를 통신도구 로 같이 쓰게 된다. 또한 이 라이브러리는 분산 학습에

서 사용되는 여러 프로세스를 그룹으로 묶어 관리하는 기능을 제공
한다. 

**3. ViT-GPT 기반 트랜스포머 모델**

연구의 실험에서 사용한3가지 트랜스포머 모델인

Seq2Seqtrainer를 활용한vit-gpt2기반 트랜스포머모델 ,일

반vit—gpt2기반 모델, BLIP 기반 트랜스포머 모델 모두 Vit
GPT를 기반 모델이다.

ViT-GPT 기반 트랜스포머 모델은 
Vision Transformer(ViT)와 GPT(Generative Pre
trained Transformer)의 강점을 결합하여,

이미지와 텍스트를 통합적으로 처리하는 멀티모달 모델이다,
